# THIRD_PARTY_NOTICES

Список сторонних компонентов, моделей, датасетов и сервисов, использованных в решении «Альфа Хак 2026 — Новостная аналитика». Версии актуальны на момент сдачи; точные версии Python-зависимостей зафиксированы в `services/agent/uv.lock`, Go-зависимостей — в `go.sum`, JS-зависимостей — в `web/pnpm-lock.yaml`.

## 1. Генеративные LLM

| Модель | Назначение | Провайдер | Доступ |
|---|---|---|---|
| `deepseek/deepseek-v4.1-flash` | Основной анализ: интерпретация события, риски, возможности, bank_view/ai_view | DeepSeek, через OpenAI-совместимый гейтвей организаторов | `https://changellenge.up.railway.app/v1` (основной), `https://api.alfahack-gateway26.ru/v1` (резервный) |
| `qwen/qwen3.6-35b-a3b` | Резервная модель (не активирована в демо) | Qwen, тот же гейтвей | — |
| `google/gemma-4-26b-a4b-it` | Резервная модель для извлечения/классификации (не активирована) | Google, тот же гейтвей | — |

Модели разрешены ТЗ (стр. 18, Приложение 3). Внешние AI-сервисы и готовые мультиагентные системы **не используются**. Fine-tuning не применяется: модель вызывается через API как есть, поведение задаётся промптом + RAG + валидацией.

## 2. RAG и эмбеддинги

| Компонент | Версия | Назначение | Лицензия |
|---|---|---|---|
| `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` | — | Эмбеддинги для semantic search по chunks | Apache 2.0 |
| `sentence-transformers` | 6.2.0 | Обёртка над моделью эмбеддингов | Apache 2.0 |
| `langchain-huggingface` | 1.2.3 | Интеграция HuggingFace-эмбеддингов | MIT |

Эмбеддинги считаются локально в контейнере агента. Чанки хранятся в `content service` (Postgres, `content_db`), агент обращается к ним через HTTP. Прямого доступа к БД нет.

## 8. Смоделированные интеграции

| Что | Как смоделировано | Что было бы в продакшене |
|---|---|---|
| LLM-гейтвей | OpenAI-совместимый endpoint организаторов | Внутренний LLM-гейтвей Альфа-Банка с согласованными моделями |
| Источник новостей | `content service` с ручной загрузкой через API и seed | RSS/парсинг/публичные API + внутренние ленты |
| Аналитика банка | PDF в `services/agent/data/`, OCR + RAG | Прямая интеграция с Alfa Research |
| Identity / сессии | `identity service` (Go), cookie | SSO интернет-банка «Альфа-Бизнес» |
| Бюджет LLM | Локальный счётчик `~/.alfa_agent/usage.json`, 450 ₽/день | Квоты внутреннего гейтвея |
| Кеш инсайтов | In-memory dict с TTL 1 час | Redis с TTL и распределённой инвалидацией |

## 10. Что НЕ используется

- Внешние AI-сервисы (OpenAI, Anthropic, Gemini и т.п.) как основной компонент — **запрещено ТЗ**, не используется.
- Готовые мультиагентные фреймворки (AutoGen, CrewAI и т.п.) как основной компонент — **запрещено ТЗ**, не используется. `LangChain` применяется только как библиотека для embeddings и text splitting, без агентной логики.
- `Qwen3-27B` и другие модели вне согласованного списка — **не используются**.
