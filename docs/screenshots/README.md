## Как пересобрать

Нужен запущенный демо-стенд (`make demo`) и Chrome/Chromium.

```bash
npm install --no-save --prefix .cache/screenshots puppeteer-core@23
NODE_PATH=.cache/screenshots/node_modules node scripts/screenshots.mjs
```

Переменные: `BASE_URL` (по умолчанию `http://localhost:3000`), `CHROME_PATH` (если браузер не находится в `PATH`), `OUT_DIR` (куда сохранять).

Скрипт входит как `demo-client@alfa.local`, снимает ленту, фильтры, разбор события (`AGENT_MODE=stub` укладывается в пару секунд), профиль и участников компании. Для скриншота разбора нужен хотя бы один новостной сюжет — его даёт `make seed`.
